Focus outline after changing browser colors

This example is intended to be tested in Firefox using browser color preferences. Go to Firefox settings, search for “color”, select Website contrast, choose Custom, and use Manage Colors to change the background color.

Then use the Tab key to move focus through the buttons below and check whether the focus outline remains visible.

The first button may fail because its focus outline uses a fixed white color. If the user changes the browser background color to white or a very light color, the focus indicator may become difficult or impossible to perceive.

The second and third buttons are safer examples because their focus indicators are based on user-adaptable colors rather than a fixed visual color.
